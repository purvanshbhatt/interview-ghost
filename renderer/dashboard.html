Stealth & Invisibility Setup

Google Meet / Microsoft Teams / Slack / Discord

100% Invisible automatically. OS-level display affinity masks Ghost windows from browser screen capture, window pickers, and desktop recordings.

Zoom Meeting Setup (Important)

Zoom uses custom desktop capture hooks. To ensure Ghost remains invisible in Zoom:

  1. Open Zoom Settings → Share Screen
  2. Click Advanced at the bottom
  3. Under Screen capture mode, select: "Advanced capture with window filtering"
  4. Never select "Advanced capture without window filtering"
